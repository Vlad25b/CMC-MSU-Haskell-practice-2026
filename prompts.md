# Промпты по проекту: анализ отзывов

## 1. Разбор ошибок и предупреждений компилятора

- **Ошибка:** `Could not load module ‘System.Directory’` → нужно добавить `directory` в зависимости.
- **Ошибка:** `Variable not in scope: isSuffixOf` → добавить `isSuffixOf` в импорт `Data.List`.
- **Предупреждение:** `-Worphans` (сиротские экземпляры) → перенести `FromJSON`/`ToJSON` в модуль с типами (`Types.hs`).
- **Предупреждение:** `-Wname-shadowing` (затенение переменных) → переименовать локальные переменные или включить `-Wno-name-shadowing`.
- **Предупреждение:** `-Wtype-defaults` (выбор типа по умолчанию) → добавить явную аннотацию типа (`:: Double`, `:: Int`).
- **Ошибка:** `ambiguous type variable` → указать тип при извлечении поля: `v .: "type" :: Parser String`.
